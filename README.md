## 🌟 Overview

This repository open-sources **50 battle-tested, professional AI engines** excavated from real-world production bookmarks, completely **translated into English**, and wrapped in sleek, zero-dependency standalone HTML5 interfaces.

- **Zero Install**: Just double-click any `.html` file in the `apps/` folder to run it locally on Mac, Windows, Linux, iOS, or Android.
- **100% Private**: All parameter synthesis happens purely in your browser. No telemetry, no backend server, no subscription lock-in.
- **Multi-Platform Launchers**: Synthesizes structured, production-grade prompts with 1-click launch buttons directly into **ChatGPT**, **Google Gemini**, and **Claude**.
